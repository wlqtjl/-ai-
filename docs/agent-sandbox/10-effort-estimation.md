# 10 · 工作量估算表（依据分级 + 三点估计）

> 对应计划「可协助做判断 · 第 10 项」，落实报告 18.3。
> 本表**替代**原报告第十四部分的单点区间估算，原因：单点区间容易被当成承诺使用。

## 1. 规则

| 依据等级 | 含义 | 是否可进排期承诺 |
| --- | --- | --- |
| **L1** | 有可直接参照的既有代码 | 可 |
| **L2** | 技术路线明确，但需新写 | 可（带三点估计） |
| **L3** | 技术路线未定 | **不可**，只能进预研，先做 spike 收敛 |

三点估计记为「乐观 / 最可能 / 悲观」，期望值按 PERT：`(O + 4M + P) / 6`。

## 4. 必须显式声明的三件事

1. **E2 与 E6 是 L3，不能进排期承诺**。它们合计占 PERT 期望的约 27%，
   却贡献了乐观-悲观区间近一半的跨度。先做 spike，再谈排期。
2. **原报告的 83-129 人天低估了 E2 的悲观情形**。如果块级翻译需要按数据库分别实现物理格式解析，
   仅 E2 一项就可能超过原报告首版的总量下限。
3. **本表新增 E12（脱敏默认开启）**。原报告把脱敏列为风险项但未计入工作量；
   既然把它定为「默认选项而非可选项」，就必须有对应的工作量。

## 5. 排期建议

```
阶段 0（预研，2 周）      : spike（E2 路径） + 09 文档 8 问确认 + 客户访谈
   ↓ 出口：E2/E6 降为 L2，否则停在这里
阶段 1（原型，3-4 周）    : E1 + E3 核心 + E4      （约 30 人天）
阶段 2（POC，6-8 周）     : E2 + E5 + E6 + E7 + E8 + E12   （约 78 人天）
阶段 3（规模化，视结果）  : E9 + E13 + E10 + E11 + P1 数据库适配
```
