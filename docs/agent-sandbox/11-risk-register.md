# 11 · 风险台账

> 对应计划「可协助做判断 · 第 11 项」，落实报告 18.7「把押注假设显式列出来」。
> 维护纪律：每两周过一次，只更新「当前状态」列；**阈值不允许在触发后临时放宽**。

## 规则

- 每条风险必须有：负责人、验证方式、**可量化的触发阈值**、触发后的应对动作；
- 「应对动作」写的是**决策**（降级/暂停/调整定位），不是「加强关注」这类无效表述；
- 触发阈值一旦满足，应对动作**自动生效**，不需要再开会讨论要不要生效。
